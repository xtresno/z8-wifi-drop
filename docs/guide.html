Z8 Wi-Fi Photo Transfer

Each photo you take in the garage appears on your PC upstairs about 2 seconds later. No cable. One-time setup: about 20 minutes.

Nikon Z8 → Wi-Fi → your PC → C:\QDAM\Listings\Incoming → ROLEX-116610_01.jpg ...
You need: the Windows PC, the Z8 with a charged battery, your home Wi-Fi name and password, and about 20 minutes. Do Part A at the PC first, then Part B at the camera.

Part A: Set up the PC (about 10 minutes)

  1. ☐ Install Python 3 from python.org/downloads. On the first install screen, tick "Add python.exe to PATH".
  2. ☐ Go to github.com/xtresno/z8-wifi-drop. Click the green Code button, then Download ZIP.
  3. ☐ Unzip it to C:\z8-wifi-drop. Do not run it from the Downloads folder; it must stay where it is.
  4. ☐ Double-click Install.bat. Click Yes when Windows asks for admin rights.
  5. ☐ If it asks "Set the network to Private?", type y and press Enter.
  6. ☐ When it finishes, open "Z8 camera settings.txt" on the desktop. Copy the values here:
SettingWrite it here
Address (this PC)
Port2121 (always)
User IDz8 (always)
Password (8 letters/numbers)
Home Wi-Fi name
Tip: the PC address can change when the router restarts. Ask whoever runs the router to give this PC a fixed address (called a "DHCP reservation"). Then you never need to change the camera again.

Part B: Set up the camera (about 10 minutes)

To save typed text, press the zoom-in (+) button, above MENU. To go back, tap the ↺ arrow at the top right.

1MENU › Network menu (the globe icon). Check Airplane mode is OFF.

2Connect to FTP server › Network settings › Create profile.

3Pick Configure manually, not the wizard. The wizard uses port 21, which is wrong here.

Step 3: pick Configure manually.

4Pick Wireless LAN.

You now see the list General / Wireless / TCP/IP / FTP. Leave General as it is.

Step 4: Wireless LAN.

5Wireless › SSID: type the home Wi-Fi name exactly. Capitals count. Tap the letters on the screen. Aa& switches between capitals, small letters and symbols. The trash-can button deletes a letter.

6Leave Authentication/encryption as it is. Scroll down to Password: type the Wi-Fi password.

Step 5: SSID is the Wi-Fi name.
The keyboard. (+) button = save.

7Go back. TCP/IP › Obtain automatically: ON. Type nothing else here.

Step 7: Obtain automatically ON.

8Go back. FTP:

  • Server type: FTP
  • Address: the PC address from Part A. The dot (.) is on the symbols page (Aa&).
  • Folder: leave blank
  • Port: change 21 to 2121. Left/right = move, up/down = change digit.
  • PASV mode: ON
Before: Port says 21. Change it to 2121.

9Scroll down in FTP:

  • Anonymous login: switch to OFF. It starts ON, and ON does not work.
  • User ID: z8 (small letters)
  • Password: the 8-letter password from Part A (small letters)
Wrong: Anonymous login ON. Switch it OFF, then fill in User ID and Password.

10Back out to Network settings. Highlight your profile (WLAN1, WLAN2 ...) and press OK to connect.

"FTP" in green on the shooting screen = connected. Red = error (see Part E).

To edit a profile later: highlight it and press RIGHT, not OK.

The yellow outline marks the profile in use.

Part C: Upload options (one time, about 1 minute)

MENU › Network menu › Connect to FTP server › Options:

OptionSet toWhy
Auto uploadONEvery shot is sent by itself.
Upload RAW + JPEG asJPEG onlyA RAW file is 50 MB and takes 4.5 s; a JPEG takes 1.6 s.
Keep connectionONThe camera reconnects after a Wi-Fi drop (uses more battery).
Overwrite if same nameOFFA photo already sent is never replaced.
Delete after uploadOFFThe memory card stays as a backup.

Also set the camera clock: Setup menu › Time zone and date. Match the PC clock, including daylight saving time.

Part D: Every shoot

  1. Turn on the camera. Wait for "FTP" in green.
  2. On the PC, double-click Z8 Photo Sorter on the desktop.
  3. Type the item ID (for example ROLEX-116610) and press Enter.
  4. Shoot. Each photo becomes ROLEX-116610_01.jpg, _02 ... in C:\QDAM\Listings\ROLEX-116610\.
  5. Next item: wait until the last photo shows up, then type the next ID.
Two PCs, one camera? Make one profile per PC (for example WLAN1 = upstairs PC, WLAN2 = other PC). The camera sends to one PC at a time: in Network settings, highlight the PC's profile and press OK.

Part E: If something is wrong

What you seeDo this
"FTP" is red on the cameraCheck the Address, Port 2121, User ID z8, and the password. Check that Anonymous login is OFF.
The camera cannot find the Wi-FiRetype the Wi-Fi name and password. Capitals count. Move the router or the camera closer.
It worked yesterday, not todayThe PC address may have changed. Open "Z8 camera settings.txt", or run Install.bat again, and compare with the camera's Address.
No photos arrive, "FTP" is greenOptions › Auto upload ON. Is the PC on and awake?
Photos are slowOptions › Upload RAW + JPEG as › JPEG only. Weak Wi-Fi in the garage: add a mesh node or access point there.
Anything elseAsk Claude Code (below).
Ask Claude Code for help. Open a terminal in C:\z8-wifi-drop, run claude, and say what you see, for example: "the camera says FTP in red, help me fix it". It reads the logs on this PC and walks you through the camera menus one step at a time. Take photos of the camera screen and give them to it.
